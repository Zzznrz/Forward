# Forward
Individual 2D Project for CS583

## Reference prototype controls

- The player runs right automatically.
- `Space` or `Up` jumps.
- `A`/`D` or the arrow keys steer.
- `S` or `Down` slides.
- Falling below the level restarts the scene automatically.
- Reach the red finish marker to complete the level; press `R` to replay.
- The start screen offers Level 1 (easy) and Level 2 (harder).
- Press `Esc` during a run to open the pause menu.
